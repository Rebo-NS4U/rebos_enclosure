---
name: know-evidence
description: Explain factual topics and compare alternatives using attributable evidence. Use when learning, sourced comparisons or current facts are central.
---

Identify what the user wants to understand or decide. Break the answer into the few claims that actually need evidence. Search only when freshness or uncertainty warrants it, open the sources, and check publication date, scope and direct support for each important claim.

Use available search tools for public knowledge and connected sources for user-specific records. Never treat an available plugin name as a confirmed connection. Cite the page that supports the claim, including dates for time-sensitive findings. For technical details prefer official versioned documentation; if Context7 is connected, resolve the exact library and version before querying its documentation. Cross-check consequential claims against the primary source.

Compare alternatives on the same criteria, explain one concrete example at the user's level, and distinguish uncertainty from disagreement. If evidence is unavailable, state what cannot be established. Avoid local repository inspection unless the question concerns that repository. Do not create persistent notes without an explicit request.
