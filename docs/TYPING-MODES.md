# Typing practice window modes

Open the ⋯ menu to switch between Typing mode and Reading mode. Each activity
supports a compact window and fullscreen independently. Choose Fullscreen or
Compact window in the same menu, or press F11. Escape leaves fullscreen while
keeping the current activity. In compact mode, Escape returns to the library.
Reading retains page navigation, word lookup and notes in either window size.
Typing retains input, caret feedback and WPM in either window size.

Run `python3 desktop/tests/check_typing_practice.py typing_modes.qml` to check
all four combinations in an isolated Quickshell window.
