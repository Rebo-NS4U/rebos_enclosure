# Remaining warning usefulness review

Reviewed after the argument/duplication cleanup. The 137 previous design observations were grouped by consequence and source responsibility. One useful hotspot exposed unbounded GPU helper processes; after repairing and extracting the NVIDIA query, the current Pylint total is **136**. There are no new suppressions or relaxed thresholds.

## What matters

1. **Prioritize** lifecycle/state and recovery code: deployment rollback and linked updates, assistant transport state, player/caption transitions, stream relay and media parsing. These warnings identify code where a small regression could affect user work or playback. They are refactoring priorities, not confirmed vulnerabilities.
2. **Useful when changing the area**: large GitHub/media action dispatchers, platform-specific monitoring and configuration parsing. Separate vendor/action handlers can improve readability. Avoid a repo-wide rewrite for the sake of a threshold.
3. **Keep as designed**: single-purpose helper classes, rejection guard clauses, framework callback signatures, widget handles and clearly named palette/image intermediates. Do not create artificial methods, merge independent checks or replace explicit variables with dictionaries just to silence a warning.

Counts below are warning instances, often several on the same function; they are not counts of independent bugs:

- Prioritize: 46
- Useful when changing this area: 61
- Keep as designed: 29

## Concrete issue found and fixed

system_monitor.get_gpu_stats issued nvidia-smi without a timeout. GPU-name discovery also called lspci without a timeout. Either child could hang the monitor. Both queries now have a three-second bound. NVIDIA query handling is isolated with complete fallback values, suspended GPUs are still skipped, and a later successful sample can recover after a timeout. No live hardware command was used by the regression tests.

Four regression tests passed against both source and installed code: timeout followed by recovery, suspended GPU without a command launch, missing/malformed query output, and PCI-name query timeout. Ruff and payload verification passed. The installed source matches the checkout. No monitor or desktop process was restarted; the script is picked up on its next launch.
