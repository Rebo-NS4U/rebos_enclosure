# Rebos Enclosure v1.4.0

Automatic English subtitles can now transcribe English and translate other
languages within the same video. The assistant also applies the repository-first
GitHub workflow across projects and backends.

## Changes

- Auto-detect each speech span's language with the local multilingual Whisper
  model and output English captions. English retains word timing; translated
  phrases retain speech-span timing. Silence gaps and seeking retain the original
  timeline, including when one caption track contains both kinds of timing.
- Add **Auto-detect language and translate to English** to Anime Streamer Settings.
  Disable it for English-only transcription. Changing this setting replaces the
  caption worker without restarting playback. YouTube retains its own captions.
- Deliver the GitHub workflow to new and older restored assistant conversations,
  across backends. Work starts in the owning repository, keeps shipped files in
  sync, and automatically commits and pushes tested task changes to the verified
  existing remote. Delivery survives chat restoration and bridge reconnection;
  failed sends do not consume it. Unrelated work and approval requirements remain
  protected. Releases are created when requested.
- Include the earlier subtitle changes in the installer payload, with regression
  tests and updated checksums.

## Subtitle setup and accuracy

Whisper binaries, the Silero VAD model and language models need separate local
setup. Downloaded models are not included in this source release. Auto mode needs
`~/.local/share/anime-streamer/models/ggml-base.bin`; English-only mode uses
`ggml-base.en.bin`. Source selection and the selected audio track are unchanged.

Real English/Spanish mixed-audio checks passed. Two recordings each in French,
German, Japanese, Korean and Italian were also tested: all ten recordings had
their language detected correctly and produced valid subtitle intervals, but French/Italian
translations were mixed and German/Japanese/Korean translations had substantial
meaning errors. Processing took 0.96–1.90 seconds per 3.86–6.53-second recording.
These are short sample checks, not a representative accuracy benchmark. Very
short phrases, noisy audio and switches within a speech span may be inaccurate.

## Install or update

From this release's source archive or a current checkout:

```bash
bash install.sh --release v1.4.0 --dry-run
bash install.sh --release v1.4.0
```

For an existing installation:

```bash
./update.sh --release v1.4.0 --dry-run
./update.sh --release v1.4.0
```

The release pins desktop files; packages still use current Arch/AUR repositories.
Add `--files-only` to skip package upgrades. Preview before applying. Existing
personal preferences are preserved.
