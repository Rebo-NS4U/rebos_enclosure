# Rebos Enclosure v1.4.1

Desktop updates now refresh managed scripts and user service definitions while
preserving personal settings, shortcuts and custom Fish functions. This release
also completes the media playback and package-tool changes shipped after v1.4.0.

## Changes

- Refresh managed package scripts, user services and the Fish `update` command
  during updates. Backups restore their previous versions alongside application
  source; personal Fish configuration and other functions remain intact.
- Share a package menu across install, AUR and removal shortcuts. Preview Arch/AUR,
  Flatpak and Rust updates with `update --dry-run`; administrator commands use
  `assistant-sudo` and retain package-manager review and confirmation.
- Continue TV playback across released seasons, keep specials separate, enforce
  resolution limits and prepare the next episode with a bounded startup buffer.
- Pass chapter names to credits detection, restore the next-episode overlay at
  playback end, position its card at the bottom right, and improve VLC MP4
  demuxing and network buffering.
- Include player-launch and desktop-spacing fixes, plus Configuration Browser.
- Surface assistant permission requests and improve GitHub network diagnostics.
  Enable Dweebo Codex workspace networking while preserving file protections and
  approval boundaries.

## Install or update

From this release's source archive or an updated checkout:

```bash
bash install.sh --release v1.4.1 --dry-run
bash install.sh --release v1.4.1
```

For an existing installation:

```bash
./update.sh --release v1.4.1 --dry-run
./update.sh --release v1.4.1
```

The release pins desktop files; package upgrades use current Arch/AUR repositories.
Add `--files-only` to skip package upgrades. Log out and back in after updating.
