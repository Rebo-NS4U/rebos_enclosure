# Dark Collection — 1920×1200

27 dark selections from the locally installed [MAKC collection](https://github.com/makccr/wallpapers), previously outside the exact-size pack. Original colors preserved, center-cropped to 16:10 and resized to 1920×1200. Two 1080p originals use a small upscale. Sources and dimensions are recorded in SOURCES.json; images retain their original creators’ rights.

Open the gallery with Super+Shift+W and select Dark-Collection. Existing previous/next/random shortcuts include this folder.
